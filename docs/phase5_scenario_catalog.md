# Phase 5.1 Planned Scenario Catalog

This is a planning catalog, not an executable benchmark. All 15 entries are `UNVERIFIED`; actual dataset feasibility, IDs, timestamps, impact sets, and outcomes must be established during later scenario construction. Use only supported event types `PORT_CLOSURE`, `SERVICE_SUSPENSION`, and `SERVICE_DELAY`. Do not infer outcomes from these descriptions.
